HOW TO CHANGE WATCH PICTURES
============================

Put your own photos in this folder (public/images) using these exact names:

  watch-1.jpg   Rolex Submariner
  watch-2.jpg   Rolex Datejust 36
  watch-3.jpg   Rolex GMT-Master II
  watch-4.jpg   Swiston Classic Automatic
  watch-5.jpg   Swiston Heritage Chrono
  watch-6.jpg   Swiston Lady Elegance
  watch-7.jpg   Citizen Eco-Drive Promaster
  watch-8.jpg   Citizen Tsuyosa Automatic
  watch-9.jpg   Citizen Eco-Drive Chandler
  watch-10.jpg  Casio G-Shock GA-2100
  watch-11.jpg  Casio Edifice Chronograph
  watch-12.jpg  Casio Vintage A168

The photo automatically replaces the drawing on every page: product cards,
detail page, cart, brand cards and the home banner.
If a file is missing, the drawn watch is shown instead.

Tips:
- Use .jpg (lowercase). Square or portrait photos (about 600x700 px) look best.
- Keep each file under 300 KB so the site loads fast.
- If you add the file while the site is running, refresh the page (Ctrl + F5).
- The numbers match the "id" values in src/data/watches.js.
